# 🌆 Interactive Smart City with Helicopter (Scratch Project)

## 📌 Introduction

### This Scratch project displays a modern city environment with animated vehicles, a flying helicopter, and interactive features. The aim is to make the scene look realistic, engaging, and dynamic.

## 🎯 Aim of the Project

### • To build a real-life city simulation
### • To add smooth animations using Scratch
### • To apply concepts like loops, conditions, and events
### • To create an interactive user experience
## 🧩 Elements Used

### 🎭 Sprites:
#### • 🚁 Helicopter
#### • 🚗 Cars (multiple types)
#### • 🚦 Traffic Signals
#### • 🏢 Buildings
#### • 🌳 Trees and street items
### 🌇 Background:
#### • City view (Day ☀️ & Night 🌙)

## ⚙️ Working Process
### 1. 🌆 Setting the Scene
#### • Select a city background
#### • Arrange buildings, roads, and decorations properly
### 2. 🚁 Helicopter Movement
#### • The helicopter stays above buildings
#### • Moves slightly up and down to create a hovering effect
#### • Blades rotate using costume switching
### 3. 🚗 Vehicle Animation
#### • Cars move continuously on the road
#### • Each car has a different speed
#### • When reaching the edge, they restart from the beginning
### 4. 🚦 Traffic Signal System
#### • Traffic light changes between red, yellow, and green
#### • Cars stop when the light is red and move when it turns green
### 5. 🎮 User Interaction
#### • Keyboard controls added for better experience:
- ↑ key → Move helicopter up
- ↓ key → Move helicopter down
- Space key → Increase car speed
### 6. 🌗 Day and Night Feature
#### • Button to switch between day and night
#### • Lights turn on during night mode
#### • Background appearance changes
### 7. 🔊 Sound Integration (Optional)
#### • Add helicopter sound
#### • Add traffic noise
#### • Add click sound for buttons

## ▶️ Steps to Run
### 1. Open the project in Scratch
### 2. Click on the Green Flag
### 3. Use keyboard keys and buttons to interact
### 4. Observe the animations and changes
